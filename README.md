# MyDFIR-Microsoft-SOC-Challenge

The purpose for this repository is to document the exercises and challenges completed throughout the MyDFIR Microsoft SOC Challenge. This repo will contain screenshots, KQL queries, simulated incidents and written reports. 

## Project Overview

The MyDFIR Microsoft SOC Challenge is designed to provide experience with what a modern cloud SOC analyst does using Microsoft security tools. Throughout this challenge I've created my own SOC lab environment in Azure using a virtual machine hosted in VMware and Microsoft security tools such as Microsoft Sentinel and Microsoft Defender for Endpoint, configured workspaces and dashboards within the SOC environment, and craft KQL queries for investigating threats and incident response.
